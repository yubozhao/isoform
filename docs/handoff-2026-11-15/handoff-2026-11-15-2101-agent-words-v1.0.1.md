# Agent words v1.0.1: "goes straight to" comes out; a yes goes to your agent, and the words never promise more

Version 1.0.1 · written November 15, 2026, 9:01 PM Pacific, by Claude Design.

**This file adds one rule to agent-words v1.0.0; everything in it stands.** agents-join v1.0.0 settled that a yes reaches an agent directly only when Isoform can start it (on this computer, or in the cloud); an agent in its own app opens with the task written in and the person presses send there. Six strings written today still say a yes "goes straight to" the agent. For an agent in its own app that's a promise the product can't keep, so it comes out everywhere.

A change goes in a new file with a new version; this one isn't edited after it's written.

## The rule

4. **Say "goes to", never "goes straight to" or "instantly",** about a yes reaching an agent, on any surface. What happens next is the hand-off sheet's button and the status words (agents-join §6 and §7), which are exact.

"Skip goes straight to pairing" (phone-setup v1.1.0) is about a screen, not an agent, and stays.

## Proof

A search of the shipped English strings for "straight to" finds none about agents.
