# Computer settings v1.2.0: the menu bar popover in every state

Version 1.2.0 · written November 15, 2026, 9:16 PM Pacific, by Claude Design.

**This file adds to computer-settings v1.0.1 and v1.1.1 (the popover); everything in them stands.** They drew the popover on an ordinary evening. This draws it with Closed Eyes on, with everything answered, on the first day without a watch, and with an agents' request next.

**Board:** Isoform Computer, artboard 20 (The menu bar, every state), frames 20a to 20e.

A change goes in a new file with a new version; this one isn't edited after it's written.

## Ranked goals

1. **Closed Eyes is the first control in every state,** and says so when it's on.
2. **The popover never shows a blank:** each slot says what's true.

## The states

1. **20a · Every day:** as computer-settings v1.0.1 rule 8.
2. **20b · Closed Eyes on:** the mark is shut (closedEyes pose); the state line reads "Closed Eyes · until {time} · every device"; the first control becomes **Open eyes** (filled). The brief and the next item stay, with "You can still answer while eyes are closed." under the item (redesign v1.0.0 rule 27: you can still answer, ask and read).
3. **20c · All answered:** the item's slot says "That's everything for now." and "Next brief at {time}." No count, no streak.
4. **20d · First day:** the brief row shows a clock, "Your first brief" and "at {time}" (computer-today v1.1.0 rule 1, computer-setup rule 10); the next item is day-one work ("Next · 1 of 2 · Day one").
5. **The state line** is the mark's words, the same on every device: "seeing" or "Closed Eyes · until {time}", then the watch: "watch listening", "watch not listening", "no watch paired". It never hides the watch's state.
6. **20e · An agents' request next:** "Next · {i} of {n} · {from} asks {to}", the question, what would move, and **Open Today** only (computer-settings v1.1.1).
